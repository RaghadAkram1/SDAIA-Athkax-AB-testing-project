# دورة التجارب واختبارات A/B والاستدلال السببي

## المشروع

**هل تؤدي إضافة مساعد ذكي إلى رفع نسبة إكمال الخدمات الإلكترونية؟**

## الوصف

تدرس هذه التجربة أثر إتاحة مساعد ذكي اختياري داخل واجهة خدمة إلكترونية، لمساعدة المستخدمين على فهم الخطوات والإجابة عن استفساراتهم أثناء تقديم الطلب. يهدف المشروع إلى تحديد ما إذا كانت الميزة تحسّن نسبة إكمال الخدمة دون زيادة الأخطاء أو الحاجة إلى الدعم البشري. **البيانات محاكاة لأغراض تعليمية، ولا تمثل مستخدمين أو منصة حقيقية.**

## السؤال والفرضية

- **السؤال:** هل تزيد إتاحة المساعد الذكي نسبة إكمال الخدمة خلال 24 ساعة مقارنة بالواجهة الحالية؟
- **الفرضية:** إتاحة المساعد الذكي ترفع نسبة الإكمال من خلال تقليل الغموض وتقديم إرشادات فورية للمستخدمين.
- **القرار:** تقييم إطلاق الميزة بالاعتماد على الأثر الإحصائي والعملي ومقاييس الحماية.

## التصميم

- **وحدة العشوائية:** المستخدم، بتوزيع 50/50 وتعيين ثابت باستخدام `SHA-256`.
- **المجموعة A:** واجهة الخدمة دون مساعد ذكي.
- **المجموعة B:** الواجهة نفسها مع مساعد ذكي اختياري.
- **المقياس الرئيسي:** نسبة إكمال الخدمة خلال 24 ساعة من إجمالي المستخدمين الموزعين، وفق مبدأ `ITT`.
- **مقاييس الحماية:** معدل الأخطاء ومعدل التواصل مع الدعم البشري.
- **حجم العينة والمدة:** 1,471 مستخدمًا على الأقل لكل مجموعة، بافتراض معدل إكمال أساسي 60%، وأصغر أثر مهم 5 نقاط مئوية، وقوة 80% ومستوى دلالة 5%. خُطط للتجربة لمدة 14 يومًا، بمتوسط 500 مستخدم مؤهل يوميًا (7,000 مستخدم إجمالًا).

## التحليل

شمل التحليل فحص جودة البيانات واختلال نسبة التوزيع (`SRM`)، ثم مقارنة نسب الإكمال بين المجموعتين باستخدام اختبار النسبتين وفترة ثقة 95% بطريقة `Newcombe–Wilson`. كما استُخدم `ANCOVA` مع ضبط النشاط السابق للتجربة كتحليل حساسية، وفُحصت مقاييس الحماية قبل اتخاذ القرار.

## النتائج والتوصية

- **الأثر الرئيسي:** ارتفعت نسبة إكمال الخدمة من **61.45%** في المجموعة A إلى **66.39%** في المجموعة B، بفارق **+4.95 نقطة مئوية** (فترة الثقة 95%: **+2.70 إلى +7.19** نقطة؛ `p = 0.0000164`).
- **مقاييس الحماية:** ارتفع معدل الأخطاء من 3.00% إلى 3.54%، وانخفض التواصل مع الدعم من 11.59% إلى 10.76%. لم يُرصد تدهور دال إحصائيًا في أي منهما.
- **التوصية:** عدم الإطلاق الشامل حاليًا، وإعادة اختبار الميزة في تجربة أكبر مخططة مسبقًا. فالتحسن دال إحصائيًا، لكن تقديره النقطي أقل بقليل من الحد العملي المحدد مسبقًا (5 نقاط مئوية). وتظل النتائج خاصة بالمحاكاة ولا تثبت أثرًا في بيئة تشغيل فعلية.

## طريقة التشغيل

يتطلب المشروع Python 3.10 أو أحدث. من المجلد الرئيسي:

```bash
python -m pip install -r requirements.txt
python main.py
```

ينفذ `main.py` مراحل المشروع الأربع بالترتيب، ويحفظ الرسوم والتقارير في `outputs/`.
